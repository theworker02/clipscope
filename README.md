# clipscope

Clip color scope values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/clipscope/

## Install / run

```bash
git clone https://github.com/theworker02/clipscope.git
cd clipscope
node src/cli.js
node --test
```
